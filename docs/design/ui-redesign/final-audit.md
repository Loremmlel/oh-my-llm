# 字体与子页面收尾审查

日期：2026-10-11。分支：`feat/ui-redesign`。本轮按用户要求完成字体裁剪，并扫描全部七个 feature 的 presentation、路由、共享控件和已有行为测试。不是仅替换配色。

## 字体交付

宋体子集包含完整 8105 规范汉字、2990 个源字体非汉字字符；保留全部可变字重和布局表。源／输出 cmap、字宽和轴范围逐项校验，两次独立生成哈希相同。宋体从 25,125,512 降到 7,635,316 字节；完整黑体继续作为界面与缺字后备。可复现清单、脚本、来源及许可见 [字体资产](../../../assets/fonts/README.md)。

Windows Release 构建通过，实际 `data/flutter_assets/assets/fonts/` 内为 7,635,316 字节宋体，哈希与源仓库相同，黑体与两份 OFL 文件齐全；没有把完整宋体额外打包。两种字体资产合计减少 16.68 MiB，未将它当作压缩后安装包体积收益。

## 参考图与有意差异

以 `01-preset.png`、`10-mobile.png` 对照编辑布局；其余页面延续 `00`—`09` 已批准的结构。没有独立参考图的过滤／检查点／详情弹窗，沿用“平铺列表、细线分隔、正文优先”的共同规则。手机编辑内容按自然高度扩展并允许整体滚动，避免键盘出现后把全部空间锁死在固定高度编辑器中；不复刻图片里的示例字号和空白。

- 两类原生依赖弹窗的真实组件渲染：桌面 1506×1045、手机 390×844 共 4 项通过，实际加载两种字体与 Material Icons；截图为 `logs/ui-audit-filter-*.png` 和 `logs/ui-audit-checkpoint-*.png`。测试使用独立状态，不启动 Windows 桌面应用。

- `flutter build windows --release --no-pub`：首次通过后，最终代码再次构建通过，81.1 秒；发布字体资源大小／哈希和许可证检查通过。
- `designmd lint DESIGN.md`：0 错误、7 个既有 token 引用警告；静态 premium audit 的 49 项仍来自旧 HTML，不解析 Dart，不用其结果宣称 Flutter 视觉通过。

浏览器使用生产组件和独立内存 fixture，刷新后分别检查桌面和手机。预设执行下移、取消退出确认、继续编辑、保存返回；其它浏览器操作与截图保存在 `logs/ui-audit-*`。依赖 SQLite 的过滤／检查点不冒充 Web 运行，布局以真实 widget 渲染核对，业务流程由全量测试覆盖。无数据库或网络协议改动。

本轮浏览器截图覆盖预设编辑／只读详情／退出确认、服务商列表／编辑、Agent 工作区／配置、历史、收藏／深色阅读、聊天、同步与媒体。桌面为 1506×1045，手机为 390×844；另实际切换聊天输入区收起／展开与媒体标准／紧凑密度。参考图的示例内容不作为功能契约，预览中的内存保存与示例资源不代表真实设备同步或模型调用已经验收。

没有操作用户原生桌面；没有 Android 构建、真机 IME／软键盘、原生字体回退及长文性能测量。本轮证据不能替代这些平台专项验收。
