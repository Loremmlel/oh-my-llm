## 字体交付

宋体子集包含完整 8105 规范汉字、2990 个源字体非汉字字符；保留全部可变字重和布局表。源／输出 cmap、字宽和轴范围逐项校验，两次独立生成哈希相同。宋体从 25,125,512 降到 7,635,316 字节；完整黑体继续作为界面与缺字后备。可复现清单、脚本、来源及许可见 [字体资产](../../../assets/fonts/README.md)。

Windows Release 构建通过，实际 `data/flutter_assets/assets/fonts/` 内为 7,635,316 字节宋体，哈希与源仓库相同，黑体与两份 OFL 文件齐全；没有把完整宋体额外打包。两种字体资产合计减少 16.68 MiB，未将它当作压缩后安装包体积收益。

## 最终旧代码清理（2026-10-11）

按用户“不为旧兼容入口保留历史包袱”的要求，再从 `main.dart` 遍历生产 import／export，并检查 UI 公共类调用、全部页面路由、Card／底板／阴影及大圆角使用。删除以下已无生产用途的内容：

- `AppConstrainedContent`：无调用的限宽包装组件。
- `ChatDefaultsSection`：仅被 barrel 导出、没有调用的旧默认选择表单；聊天最近选择的记忆逻辑仍由聊天控制器维护。
- `pagination.dart`、`history_widgets.dart`：无导入方的导出文件。
- `AppRadii.lg/xl`：无引用的旧 18／24 大圆角。
- 预设编辑的旧弹窗分支：组件改名为 `PresetPromptEditor`，统一页面布局、退出保护与保存路径。随仓库维护的 widget preview 和行为测试同步改用页面入口。
- `/favorites/:favoriteId` 旧扁平地址重定向及专用兼容测试；收藏内容使用 `/favorites/items/:favoriteId`，重建恢复与已删除记录测试改用正式地址。

清理后 451 个生产 Dart 文件全部可由入口静态到达，UI 公共类扫描没有仅声明而无调用的候选项；该检查不把“文件可达”误称为所有成员都已执行。当前 14 个 GoRoute 均承担实际页面与子页面入口，没有发现需要整页删除的孤立页面。更新了设计文档中侧栏模式的过时说明与卡片旧注释。

残余 Card 是聊天输入区、收藏夹导航、内联错误／空回复；图片容器、已存在模型标记和通知阴影表达媒体、状态或浮层，不是旧的嵌套配置卡片。本轮保留已认可的外观，不新增另一套视觉变体。没有数据库、领域数据或网络协议改动。
