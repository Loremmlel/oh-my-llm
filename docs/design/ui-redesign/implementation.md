# 首批 UI 实施记录

日期：2026-10-10。分支：`feat/ui-redesign`。

## 实施范围

- 字体：Noto Sans SC 用于界面与编辑；新增本地完整 Noto Serif SC 用于页面标题、聊天 Markdown 正文。代码样式保留等宽字。此次没有裁剪字体，新增文件约 23.96 MiB；来源和许可证见 [字体说明](../../../assets/fonts/README.md)。
- 共享基础：暖白／灰绿／深绿浅色主题、对应深色主题，使用既有间距、命中区域和表单组件。保留 Material 的焦点、键盘、可访问性基础。
- 聊天：助手正文平铺、用户消息浅色块、统一阅读宽度。宽窗口把历史／预设嵌入唯一侧栏，设置和同步放底部；较窄或矮窗口保留按需抽屉，窄屏保留底部导航。
- 预设：设置中的新增／编辑进入 `/settings/presets/new` 或 `/settings/presets/:presetId`，不传实体快照。名称与语法并排，上下移动在条目顶部；桌面编辑区使用剩余高度，窄屏自然换行并滚动。取消与返回保护未保存修改；保存失败内联显示并保留输入。
- 修复浏览器预览发现的 ID 随机上界问题：将会在 JavaScript 中位移为零的 `1 << 32` 改为等值整数常量，原生 ID 格式与范围不变。

数据库、协议、持久化格式与 generation 生命周期未改变。没有新增概念图中的业务能力。

## 后续范围

### 层叠容器修正

首版仍保留预设左右大圆角面板、输入框套卡片、推理框和药丸工具栏，用户指出与参考图不符。本次删除这些多余容器：预设改为分隔线两侧的平面列表与编辑区，名称／语法放在编辑区顶部，标题／角色／位置并排；聊天正文输入取消内部边框，配置移至正文下方，推理改为无框展开行，辅助开关使用轻量选中背景。

预览改用生产 `ChatComposerCard`，不再用手拼的简化输入区。为使该组件能独立预览，把原状态文件里的纯 composer 数据对象原样移至独立文件，避免预览连带引入 SQLite；数据对象、Provider 和数据库行为不变。浏览器示例仍不连接真实模型、不读取个人数据库。

本轮最终验证：1903 项测试通过（2 分 08 秒），静态分析无问题，451 个文件导入边界检查通过。内置浏览器检查 1280×900／390×844、深浅色、推理展开／收起、窄屏更多设置。截图在 `logs/ui-flat-chat-desktop.jpg`、`ui-flat-chat-dark.jpg`、`ui-flat-chat-narrow.jpg`、`ui-flat-preset-desktop.jpg`、`ui-flat-preset-narrow.jpg`。热重启期间曾出现 Flutter Web 的 disposed view 调度警告；后续页面正常渲染与交互，不将 Web 热重启作为原生验证。

其它页面仍只继承共享主题，尚未逐页实现参考图结构。字体 8105 字子集、原生性能与发布包体积待后续专门验收；不能沿用旧字体性能数据作新字体结论。

### 输入区重新排版

用户指出输入区仍像设置表单。本轮取消正文浮动标签，以简短占位提示进入编辑；服务商、模型、模板使用无框的紧凑下拉，与图片入口、发送组成底部工具栏。桌面思考、重试、固定顺序、过滤与缓存状态移到外边界下方，窄屏使用带状态摘要的更多设置图标。下拉保留原生菜单、选中值提示及服务商／模型／模板可访问名称。

收起输入区属于常用动作，按用户补充意见固定在正文右上角，桌面与窄屏均直接可达，不进入更多设置。发送／停止仍处于同一稳定位置；模板校验或图片处理阻止发送时，按钮同时呈禁用态，运行中的停止不受此影响。模板变量、图片、编辑取消、快捷键和会话草稿继续沿用现有流程，没有数据库改动。

内置浏览器使用生产 composer 和独立示例数据检查 1280×900、390×844、深浅色、窄屏收起／展开与更多设置。截图为 `logs/ui-composer-desktop.jpg`、`ui-composer-narrow.jpg`、`ui-composer-dark.jpg`，输入区细节为 `ui-composer-detail.jpg`。预览不连接真实模型；发送回归由测试中的 fake client 覆盖，未运行原生桌面应用。

更新原有测试定位，使正文和模板用所属组件定位、模型用可访问名称定位，不再依赖已移除的浮动标签。窄屏图片编辑等待布局动画并滚动到操作入口后点击。新增校验禁用与运行中停止的回归，并在宽窄断点测试中检查常驻收起按钮的回调。

本轮最终全量测试 1904 项通过（2 分 07 秒），静态分析无问题，451 个文件导入边界检查通过，暂存 Dart 格式检查与 diff 空白检查通过。

### 设置导航、服务商与预设列表

用户认可输入区后，下一批按 `03-providers.png` 和 `07-presets.png` 落地。设置顶部保留六个分类，新增服务商位于分类区域右侧；提示词下拉直达记忆、模板、固定顺序三个既有分组，点击主标签恢复总览。导入／导出宽屏显示文字、窄屏使用图标；导出范围和敏感内容确认不变。共享壳层的宽屏顶栏移入主内容列，侧栏从顶部贯穿到底。

服务商使用一层薄边界，展开显示可复制的连接地址、密钥保存状态和模型表格；模型能力改为桌面复选框，窄屏保留原能力控件。新增、编辑、删除与既有能力持久化继续复用；批量添加按钮直接打开原 API 拉取模式，没有新增协议或业务能力。删除不影响聊天记录，最近选择清理逻辑保留。

预设列表取消摘要卡片，改为名称、语法、条目数量、单条 System 和操作五列；编辑进入已有独立编辑页，复制仍导出到剪贴板，删除增加既有标准确认弹窗。复制、开关与删除等待时禁止重复操作，失败内联提示并允许重试。无数据库、数据格式或生成流程改动。
