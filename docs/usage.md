# 四月使用指南

[返回项目首页](../README.md)

本文介绍模型配置、聊天、提示词、写作 Agent，以及设备同步与数据存储。

## 服务商与模型

在 **设置 → 服务商** 中先新增服务商，再在所属服务商下添加模型。

| 配置项 | 说明 |
| --- | --- |
| 服务商名称 | 用于区分不同接口，例如「DeepSeek 官方」或「OpenRouter」。 |
| API 模式 | 选择 Chat Completions、Responses 或 Anthropic Messages，该服务商下的模型共用此协议。 |
| API URL | 可以填写域名、API 根地址或完整生成端点，应用按所选协议解析。 |
| API Key | 服务商提供的接口密钥。 |
| 显示名称 | 模型在应用中的名字。 |
| API 模型名称 | 服务商实际接受的模型标识，原样发送给 API。 |
| 支持深度思考 | 开启后，聊天页提供思考选项。 |
| 多模态 · 图像 | 仅在模型支持图片输入时开启。 |

添加模型支持手动输入和从 API 拉取。聊天页先选择服务商，再选择其下的模型。

开启深度思考后，应用按协议发送相应配置：Chat Completions 使用 `reasoning_effort`，Responses 使用 `reasoning`，Anthropic Messages 使用自适应 thinking。协议由服务商配置决定，应用不会根据模型名称或域名自动猜测。

## 聊天与长对话

### 阅读与图片输入

正文支持 Markdown、代码高亮和 LaTeX 公式，推理内容在独立区域展开查看。界面操作与编辑使用 Noto Sans SC，阅读使用 Noto Serif SC；字体随应用打包，无需启动时下载，正文字号可在设置中调整。

图文消息需要选择已开启图像能力的模型。图片可以在发送前预览；含图片的历史上下文也受模型能力限制。

流式回复增长时不会持续自动滚动到底部，便于停留阅读前文。打开或切换会话时定位到最新消息；原先位于底部时，新增一轮消息会定位一次。

### 分支与重试

- 编辑用户消息后发送，会创建新分支，原消息与后续回复仍然保留。
- 仅最新一条助手回复可重试，生成的不同版本可以通过版本控件切换。
- 聊天生成错误显示在对应回复内，便于结合上下文查看与重试。

### 上下文与检查点

通过上下文过滤选择哪些历史消息参与请求，也可以创建检查点并使用记忆提示词生成总结。

上下文查看展示实际请求准备后的内容；生成过程中查看的是本次请求快照。检查点记忆、预设、历史消息和最新输入的拼接顺序见[预设 Prompt](#预设-prompt)。

### 自动重试与输出处理

自动重试支持两种模式：

- **每分钟窗口**：在每分钟前 n 秒内随机选择时间重试。
- **固定间隔**：等待指定秒数，并加入最多约 1 秒的随机延迟。

输出正则规则在 **设置 → 输出处理** 中管理，按配置顺序依次应用。

## 提示词

### 预设 Prompt

预设由有序的 System、User、Assistant 条目组成，每条可以单独启停并指定注入位置。支持普通文本、有限宏语法、SillyTavern 导入，以及将 System 内容合并的「单条 System」选项。

预设在独立页面编辑，条目排序与语法选择位于顶部。保存失败保留输入，离开时提示未保存修改；在聊天侧栏选择要使用的预设。

实际请求按以下顺序组装：

1. 检查点记忆消息。
2. 预设中位于历史之前的消息（`before`）。
3. 经过上下文过滤的历史消息，不包含本次最新输入。
4. 预设中位于最新输入之前的消息（`beforeLatestInput`）。
5. 本次最新用户输入。
6. 预设中位于最新输入之后的消息（`after`）。

宏预设先按条目列表顺序求值，再按注入位置组装；普通预设不执行宏。SillyTavern 导入与宏支持有范围限制，不等同于完整的 SillyTavern 运行环境；导入时查看结构差异和宏诊断。

### 模板提示词

模板用于复用输入格式。在聊天输入区选择模板后，填写变量并发送。变量支持三种类型，未标注类型时默认为文本：

```text
{{主角名字}}              # 文本
{{章节数:number}}         # 数字，只接受十进制整数
{{人称:select|一|二|三}}   # 单选，按声明顺序展示
```

`{{正文}}` 对应主输入框，只能出现在条件块之外，不能声明为数字或单选。单选变量保存选项的字符串值，调整选项顺序后历史值仍然有效。

使用条件块可以根据变量选择不同内容：

```text
{{#if 人称 == "一"}}
以第一人称叙述。
{{else if 人称 == "二"}}
以第二人称叙述。
{{else}}
使用第三人称叙述。
{{/if}}
```

按顺序输出第一个成立的分支；所有条件均不成立且没有 `else` 时输出空字符串。

| 变量类型 | 比较运算符 | 右值 |
| --- | --- | --- |
| 文本 | `==`、`!=` | 双引号字符串。 |
| 单选 | `==`、`!=` | 双引号字符串，且必须是已声明选项。 |
| 数字 | `==`、`!=`、`>`、`>=`、`<`、`<=` | 十进制整数。 |

切换分支时，隐藏字段保留当前草稿值，切回时恢复；控制条件的变量始终显示。

当前不支持嵌套条件、多个条件的布尔组合、模板引用、模板预览，以及选项中的 `|` 转义或字面量 `{{` 转义。

### 固定顺序提示词

适合对不同模型或配置逐步发送同一组输入：

1. 在设置中创建序列，每步填写一条用户消息。
2. 从聊天输入区打开 **固定顺序提示词**，窄屏入口位于更多设置中。
3. 选择序列与步骤，查看正文和进度。
4. 选择「填入输入框」只将正文放入输入区，再次打开时仍停留在当前步骤。
5. 选择「发送当前步骤」直接发送，再次打开时定位到下一步；到最后一步后仍停留在该步。

序列由你逐步执行，不会自动发送整套内容。

### 记忆提示词

在设置中创建不同风格的总结提示词，生成检查点记忆时选择使用。

## 写作 Agent

从 **Agent** 入口新建作品。每部作品独立管理会话、草稿、模型与角色配置、工作文档和剧情状态。

- **模型与规则**：配置主 Agent 与不同职责的模型，保存和应用配置方案；运行中配置只读。
- **工作资料**：管理人物卡、世界书、剧本和写作笔记，供模型按职责使用。
- **正文与执行过程**：优先显示采用的正文，推理、工具调用和子任务按需展开；运行中可以停止整棵任务树。
- **上下文**：查看下一次输入预览，以及模型步骤实际使用的输入。
- **累计总结**：按连续楼数整理正文，可编辑、重新总结或恢复原文，原始记录仍保留在本地。
- **重试与撤回**：支持最新回复重试和撤回最新一轮；操作前会说明对正文、子任务与状态的影响。

历次实现与验证记录见 [Agent 开发记录](agent/README.md)，其中较早阶段的行为描述保留作为历史参考。

## 历史与收藏

历史页按时间分组，支持分页、重命名和批量删除。搜索匹配对话标题与用户消息，不匹配助手回复；手动命名的对话不再显示消息摘要。

点击助手消息上的书签按钮即可收藏。收藏保存提问、回复与推理内容的完整副本，即使来源对话被删除仍然保留。

收藏页支持按全部、未分类或指定收藏夹筛选，也可以批量移动。删除收藏夹时，可以把内容移到其它收藏夹或未分类，也可以确认一并删除内容；收藏详情支持跳回来源对话。

## 局域网同步与媒体

### 设置同步

设备配对后，可以按分类同步服务商、预设、提示词、网络、输出处理及其它设置，**不包含聊天记录**。

首次连接使用一次性配对码。同步数据加密传输，未配对或未授权设备不能读取；API Key、自定义请求头等敏感分类需要发送端与导入端分别确认。

### 媒体浏览

在连接页配置 Windows 的媒体根目录后，通过 **媒体** 标签页浏览：Windows 直接读取本地目录，Android 通过已配对的局域网设备访问同一目录。

支持目录与路径导航、图片查看、视频播放和随机播放。媒体网格提供紧凑、标准、舒适三档密度，各设备独立保存选择。

Windows 视频快捷操作：

| 操作 | 按键或手势 |
| --- | --- |
| 播放与暂停 | 单击。 |
| 快退与快进 | `←` / `→`，每次 5 秒。 |
| 临时倍速 | 长按 `→` 400 毫秒后，临时 3 倍速。 |
| 音量 | `↑` / `↓` 或垂直滚轮，每次 5%；`M` 静音。 |
| 全屏 | `F` 或双击；`Escape` 退出全屏或关闭。 |

Android 使用触摸手势：单击显示控制栏、双击快退或快进 15 秒、长按临时 3 倍速、横向拖动调整播放位置。

## 数据与日志

### 本地存储

SQLite 文件 `chat_history.sqlite` 位于应用 Support 目录，保存聊天记录、收藏、提示词，以及 Agent 作品与运行资料。服务商、模型、字号、请求头和自动重试等配置使用系统 SharedPreferences 保存；长期配对密钥使用系统安全存储。

设置导出文件带版本号，受支持的旧格式按顺序迁移，不支持的版本与未来版本会明确拒绝。设置导出与同步均不能替代聊天记录或 Agent 作品的备份。降级应用前先备份数据，旧版本可能无法读取新数据库或条件模板。

### 自定义请求头

在 **设置 → 网络** 中配置外部模型请求的 HTTP Header，同名项覆盖默认值。局域网同步与媒体连接使用独立的 HTTP 客户端，不继承模型 API 的 Key、Cookie 或自定义 Header。

### 网络日志

`network.log` 与 SQLite 数据库位于同一目录，用于定位请求、流式传输和错误。默认记录请求标识、响应状态与诊断信息，不记录请求正文；敏感 Header 统一脱敏。

正文诊断只在明确启用的路径记录，工具与原生续接请求仅保留无内容摘要。日志超过 10 MB 时重置，退出或重新启动应用不会主动清空。

反馈问题时，仅提供与故障相关的日志片段，并检查是否包含个人内容或接口凭据。
