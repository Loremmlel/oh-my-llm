# 说明文案治理记录

日期：2026-10-07。目标：把主要区域还给内容与操作，以按需帮助承载静态解释。

## 扫描范围与判定

对 `lib/features/*/presentation`、`lib/core/widgets`、应用 shell/composition 的 `Text`、`SelectableText`、`helperText`、`subtitle`、`description`、Tooltip 和现有折叠说明进行静态扫描，再读取候选组件和调用点。覆盖对话、历史、Agent、收藏、设置、同步和媒体；不是所有页面的原生设备逐屏验收。

图片中的作者声明属于用户的 Prompt 内容，不修改。治理对象是编辑器周围的应用说明。

## 保留项

- 历史、收藏：会话预览、收藏正文、数量、空状态、无效链接和删除后果是内容或即时状态，没有发现应迁移的常驻教程块。
- 媒体：路径、播放进度、音量、速度、失效会话与加载错误是当前信息；手势文档为代码注释，不是屏幕文案。
- 同步：配对码、地址、广播状态、网卡不可修改原因、敏感凭据确认及导入结果保留。
- 检查点：是否附带预设、覆盖范围、继续携带完整上下文等选项后果与状态保留。
- 通用空状态、拉取模型提示及模型缺失提示保留短指引，不为没有主要内容的页面添加多余帮助入口。
- 业务详情的折叠展示（推理、工具、来源正文、导入诊断）保留；它们承载实际数据，不属于静态说明。

## 组件和规范

规范唯一入口为 [DESIGN.md](../DESIGN.md#说明文案与主区域空间)。`AppHelpButton` 只接受标题和文案，`AppHelpTitle` 处理标题相邻布局，复用现有 `DetailDisplayDialog` 和 `AppDialogActions`。不新增帮助注册框架、应用状态或依赖。

原设计约定中的“分组说明常驻”“模型单独编辑保留说明文字”已改为按需帮助。主题、间距和对话框行为继续由既有运行时组件拥有。
