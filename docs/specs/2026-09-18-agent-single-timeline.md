# Agent 单时间线与累计压缩

## 产品行为

一部作品只拥有一条主 Agent 时间线、一个草稿和当前配置。移除会话模型、表、选择器、新建与改名入口。新建作品才建立独立的文档、剧情状态和上下文。配置方案仍属于作品；应用配置直接影响后续调用，不清空作品成果。最新主 Agent 回复仍可覆盖式重试，沿用原 ID 和位置；切换模型后的重试采用当前配置并更新实际模型标签。

## 累计压缩

用户选择从最早未压缩正文开始的连续楼数。首次读取选定原稿与对应写作指令；后续读取当前累计摘要、新增原稿和对应指令，生成一份完整累计摘要。成功后原子替换当前摘要，失败、取消或保存失败则维持原摘要和范围。重新总结当前累计范围时允许从保留的全部来源原稿重新生成。

每个主任务保存 `historyEnd`，表示它在原始时间线中的排他结束位置。摘要绑定累计 `roundIds` 与最后任务的 `historyEnd`。下一次主 Agent 输入为：当前规则与设定、唯一有效累计摘要、边界之后的历史、当前剧本目录及有效备忘、最新剧情状态、新指令。因此覆盖范围内整段任务的工具调用、结果、推理、旧状态快照和正文副本均退出模型上下文。子 Agent 继续按职责读取同一累计摘要与未覆盖正文。

压缩不会删除本地来源正文、执行记录或实际调用输入快照，也不回退当前文档与剧情状态。恢复全部原文会停用累计摘要；撤回或重试摘要覆盖的楼层则使整份摘要失效，不能复用已撤回事实。只保留一份当前摘要，不建立可切换版本或跨会话映射。总结任务的历史执行记录仍可查看。

不支持任意主用户消息编辑；后续如实现，可在这条线性时间线上按任务边界回退并删除后缀，无需分支版本树。

## 模型与协议转换

`convertLlmHistory` 是 Agent 显式切换目标时的输入转换边界。目标由协议、解析后的端点和模型名称共同确定；同目标沿用原生 envelope，不丢签名。目标改变时剥离原生回放数据，仅保留 typed 文本、函数调用和工具结果，并重新分配可移植工具 ID、保持结果配对。公共历史通过现有 `LlmAssistantTurn.portable` 表达，由共享输入编码器生成 Chat Completions、Responses、Messages 请求，不构造模拟原生 envelope。已转换的公共历史再次切换目标时保持工具 ID。不兼容推理、签名、加密内容、厂商内置工具和其他私有字段不迁移，不提供厂商能力的兜底。

转换保持历史项数量，任务压缩边界不漂移。旧任务实际请求快照独立保留。共享协议编码器仍严格校验原生 envelope 的目标与工具闭合，不放宽现有续接约束。配置弹窗明确展示字段丢弃提示，预览与实际发送经过同一转换。

公共历史仅用于请求输入；模型返回的终态仍必须携带可靠原生回放数据，否则停止执行工具。存储通过 `portable_assistant` 与 `assistant` 区分两种历史，损坏的原生记录不自动降级；沿用现有表结构。公共历史正文与工具参数仍计入上下文字节预算。

## 数据库升级

用户明确说明 Agent 尚未正式使用，授权丢弃全部 Agent 测试数据。schema v22 仅在升级事务中清空 `agent_workspaces` 及其级联数据，移除 `agent_sessions` 和任务／正文轮次的会话外键，草稿归作品，累计摘要以作品 ID 唯一。普通聊天、消息树、收藏、提示词及服务商／模型配置不属于清空范围。

保留 v13 起的顺序迁移实现与旧 fixture；先执行历史迁移，再进入 v21 → v22。损坏历史仍按既有迁移边界显式失败。v22 重开不会再次清空。事务失败全部回滚。此升级不可通过降级程序恢复旧 Agent 测试数据；回退需恢复升级前数据库备份。最低支持版本不变。

## 验证所有权

- 转换矩阵：共享 LLM 转换测试验证三种协议组合、字段丢弃、同目标原生保留、反复切换 ID 稳定；输入编码器验证三种公共请求结构与无效工具配对拒绝。Agent 验证两种历史存储往返、请求预算与缺少原生终态时拒绝执行工具。
- 累计压缩：Agent runtime 测试验证增量来源、整段工具移除、恢复、失败／取消和摘要保存事务。
- 配置与重试：控制器验证相同作品持续发送、切换后的模型及任务标签、草稿和实际输入快照。
- 迁移：固定 v21 fixture 验证清空范围、非 Agent 数据保留、事务回滚及新作品重开保留；历史 fixture 保留迁移链覆盖。
- 界面：既有桌面／窄屏 widget 流程覆盖作品搜索与改名、配置应用、压缩取消／重试、编辑摘要和键盘弹出时保存。
