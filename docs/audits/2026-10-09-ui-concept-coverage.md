# UI 概念图：页面与功能对应清单

日期：2026-10-09。工作分支：`feat/ui-redesign`。

## 范围与依据

用户已认可单侧栏、开放正文、暖白／绿色系聊天方向，以及预设编辑从弹窗改为独立页面。本轮修正排序按钮位置与模板语法占行问题，并扩展主要页面。此文件描述需要保留的功能与候选入口，不是已实施或已验收清单。

最终图组已获认可并纳入 Git。参考图片、用户意见和 Anthropic 设计依据统一见 [UI 重构设计基准](../design/ui-redesign/README.md)；图稿中的示例状态不能覆盖下述功能约束。

核对依据：`lib/app/router/app_router.dart`、`lib/app/navigation/app_destination.dart`、`DESIGN.md`，以及各 feature 的 presentation。路由仍包含对话、历史对话、Agent、收藏、设置、同步六个主入口；媒体位于同步下，不能因视觉重组丢失入口。

## 图稿不能覆盖的业务规则

- 聊天只有最新 assistant 回复可重试。已在交付图中删除较旧回复旁的重试按钮；消息操作的最终位置还需与长文操作可达性一并评审。
- Chat 与 Agent 都保留 Enter 换行、Ctrl+Enter 发送。已将 Agent 初稿错误的键盘占位文案改回真实草稿；图稿不能改变快捷键约定。
- Agent 的停止全部随运行状态出现；不能把聊天的图片、模型输入控件直接复制到 Agent。运行中切换作品／配置的限制继续有效。
- 数字、时间、作品文字、设备与端点均为示例，不是运行数据；图中的字数不是 Token，不设生成器臆造的正文长度上限。
- 同步中的“合并／替换”按既有导入策略处理，不能从效果图推断冲突会自动保留两份。
- 预设单条 System 是预设级开关；角色字段是协议角色，不是“小说家”等业务身份；位置字段是注入位置，不是章节名称。
- 六个设置标签是本轮候选中保留的导航；具体列表、菜单与编辑页如何落地，仍需用户评审。未经确认不新增功能、不删除现有功能。
